Waypoint

Encode your file into a .gpx GPS Map!

Note:

Waypoint was developed under time constraint (to ship with bonus multipliers). As a result, I had to get help from some LLMs. Note that about 90% of the code is hand written by me. The source code is also somewhat messy, and there may be edge cases that haven't been tested or accounted for.

Given more time, I would improve the code structure, perform rigid testing, and improve my code in other small ways. Also, the bad styling is not a result of the time constraint, I'm simply just bad at applying CSS effectively.

Thank you for looking at my project!
